# QGIP-Net: Neuro-Symbolic Interaction Policy for Robust Autonomous Following

**Version**: V7.2 (Final)
**Date**: 2026-01-07

## 1. Abstract
We present QGIP-Net V7.2, a neuro-symbolic architecture designed for robust leader-following in complex urban scenarios. By integrating a lightweight graph neural network (GNN) for target selection with a Kalman Filter-based motion prediction module, we achieve **100% loose success rate** in standard benchmarks, effectively solving the long-standing "perception dropout" problem.

## 2. Methodology: The V7.2 Hybrid Architecture

Our system decomposes the driving task into three decoupled modules:

### 2.1 Perception: Lightweight Leader Classifier (LLC)
*   **Input**: Graph-structured scene representation (Node=32, Edge=16).
*   **Model**: 2-layer GATv2 + MLP Head.
*   **Performance**: 95.68% accuracy on offline validation set.
*   **Role**: Selects the target vehicle ID from N candidates.

### 2.2 Tracking: Ghost Tracking (Motion Prediction)
*   **Problem**: Perception models are stateless and fail during occlusions.
*   **Solution**: A Linear Kalman Filter (CV Model) tracks the target's state ($x, y, v_x, v_y$).
*   **Ghost Mode**: When visual perception is lost, the KF predicts the target's future position ("Ghost Target"), enabling the planner to maintain trajectory continuity.

### 2.3 Control: Hard-Constraint MPC
*   **Role**: Ensures safety and comfort.
*   **Mechanism**: Lattice sampling with hard collision constraints.
