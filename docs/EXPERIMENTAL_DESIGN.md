# 实验设计说明 (Experimental Design Note)

## 1. 实验协议 (Experimental Protocol)

为了确保实验结果的统计显著性与严谨性，特别是针对“零碰撞 (Zero-Collision)”的安全声明，我们设计了以下严格的实验协议。本协议旨在满足机器人学顶刊 (e.g., T-RO, IJRR, RAL) 的审稿标准。

### 1.1 场景与评估 (Scenarios & Metrics)
*   **Simulator**: CARLA (0.9.13)
*   **Scenarios**:
    *   **Town05 (Main)**: **多车道城市道路/快速路混合场景**，包含高速度交通流 (Multi-lane urban/expressway mix)，用于模拟复杂的跟车与交互环境。
    *   **Town03 (Generalization)**: 复杂的城市路口与环岛场景，用于验证模型泛化能力。
*   **Episode Definition**:
    *   **Start**: 车辆初始化并接收导航指令（如“跟随前车”）。
    *   **End Conditions**:
        *   **Success**: 成功完成跟车任务（保持车距、无碰撞、无丢失）达到预定时间/距离。
        *   **Collision**: 发生任何形式的碰撞（车辆、行人、静态物体）。
        *   **Lost**: 满足以下任一条件即判定为丢失：
            1.  **ID Lost**: 目标 ID 连续丢失超过 $K=20$ 帧（约 1s）；
            2.  **Distance Lost**: 目标距离超过 80m 且持续时间 $> 2.0s$；
            3.  **Timeout**: 任务超时。
*   **Metrics**:
    *   **Success Rate (SR)**: 任务成功率（Strict Success）。
    *   **Collision Rate (CR)**: 碰撞发生率（Safety Hard Constraint）。
    *   **Lost Rate (LR)**: 目标丢失率。
    *   **Kinematics**: 平均加加速度 (Avg Jerk) 用于评估舒适性。

### 1.2 故障注入 (Fault Injection)
为了模拟真实的感知不确定性（OOD），我们定义了标准化的故障注入协议：
*   **Default Protocol**: $\rho = 20\%$。即每 $T=5.0s$ 周期内，强制屏蔽传感器输入 $t_{blind}=1.0s$。
*   **Robustness Sweep**: 在鲁棒性分析中，我们将 $t_{blind}$ 在 $\{0.5s, 1.0s, 1.5s, 2.0s\}$ 范围内进行扫描。

### 1.3 控制器公平性 (Controller Fairness)
*   **Shared Control Stack**: 为了排除下游控制器的影响，**所有对比方法（Ours, Rule-Based, Ablations）均共享同一套基于 Lattice-Sampling 的 MPC 控制器**。差异仅在于上游的“感知与决策”模块。
*   **E2E Exception**: **E2E-Baseline** 代表纯“端到端黑盒控制”范式，设计上不追求 Controller Fairness，旨在对比不同范式下的安全性差异。

### 1.4 场景覆盖 (Scenario Coverage)
为了防止“只测简单样本”的质疑，每轮 Episode 的初始条件将在以下范围内**随机采样**：
*   **初始距离**: $10m \sim 30m$ 均匀分布。
*   **前车策略**: 随机选择 {Conservative (匀速), Aggressive (急加减速), Erratic (随机变道)}。
*   **交通密度**: 随机选择 {Low, Medium, High}。

## 3. 统计报告标准 (Reporting Standards)

为了满足顶刊审稿要求，我们将采用以下统计报告方式：

1.  **置信区间 (Confidence Intervals)**:
    *   对于 Success Rate，报告 **95% Wilson Score Interval**。
    *   对于 Collision Rate (若为 0)，使用 **Rule-of-Three** 报告上界：
        > "With 0 collisions in N=300 episodes, the 95% upper bound for collision rate is approximately $3/N = 1.0\%$."
2.  **配对评测 (Paired Evaluation)**:
    *   所有对比方法在相同的随机种子序列（Traffic Seeds）下运行，以消除环境方差。
3.  **显著性检验 (Significance Test)**:
    *   对于 Ours vs. Baseline 的 Success Rate 提升，使用 **McNemar Test** 或 **Paired Bootstrap** 验证统计显著性 ($p < 0.05$)。
